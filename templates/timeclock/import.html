Worth knowing

  • On the Full Clocking Report a day nobody worked prints as --:-- with zero hours. Those days are loaded too — an absence is information — and shown greyed rather than dropped.
  • Where a day was clocked more than twice the report flags it ODD Clocking and prints the full punch list underneath. Every pair is kept, because the day line above shows only the first one.
  • On the Overtime Report only days carrying overtime are printed, so each person's subtotal covers days that were never shown. Both figures are kept and displayed side by side.
  • Employees are matched to personnel by clock number, then by a remembered link, then by name. Anything left is listed for you to decide — nothing is guessed.
  • A match you make by hand is remembered, so the same number matches itself on next week's report.
  • Every row keeps the exact line the report printed, so an edit can always be reverted and the whole import can be reversed in one click.
  • The overtime loaded is checked against the report's own grand total, and the import screen says whether it reconciles.
